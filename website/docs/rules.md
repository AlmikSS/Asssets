# Правила инструментария

Эти правила сохраняют совместимость проектов CandyCandleGames с публичной [справкой API](api-reference.md), доступной на английском языке.

1. **Используйте публичный API.** Не связывайте игровой код с приватными очередями, метаданными reflection или деталями реализации Unity внутри сервисов инструментария.
2. **Объявляйте зависимости.** Регистрируйте сервисы через `[Register]`; получайте их через `[Inject]`, а не создавайте и не ищите зависимости вручную.
3. **Передавайте состояние спавнинга через `SpawnService`.** Спавнинг, деспавнинг, пулинг и изменения жизненного цикла не должны повторно реализовываться напрямую через `Instantiate`, `Destroy` или простое изменение активности.
4. **Очищайте подписки на события.** Каждый обработчик события должен отменять регистрацию при деспавнинге, отключении или уничтожении владельца.
5. **Отмечайте участников сцены.** Игровой объект, участвующий в инициализации сцены инструментария, должен иметь `SceneObject`.
6. **Выбирайте слой тиков.** Реализуйте `ISystemTickable` для инфраструктуры, `IGameplayTickable` для геймплея с фиксированным шагом, `IUITickable` для UI и `IPresentationTickable` для визуального представления.
