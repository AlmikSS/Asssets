# Примеры

В проект включена готовая сцена `Assets/_KofeyekToolkit/Scenes/SampleScene.unity`.
Откройте её в Unity **6000.5.1f1**, чтобы посмотреть, как компоненты CCG Toolkit
собираются в рабочем проекте.

## Что посмотреть в SampleScene

- `AppBootstrap` создаёт контейнер зависимостей и запускает сервисы приложения.
- `SceneObject` отмечает корневые объекты, которые нужно инициализировать вместе
  со сценой.
- `DevConsole` из `Assets/_KofeyekToolkit/Prefabs/Console/DevConsole.prefab`
  добавляет команды разработчика и вывод журналов.

## Использование в собственной сцене

Создайте сцену и добавьте в неё `AppBootstrap`. Затем отметьте инициализируемые
корневые объекты компонентом `SceneObject` и, если нужен консольный интерфейс,
разместите prefab `DevConsole`. Подробнее о порядке запуска и сервисах читайте в
разделах [Быстрый старт](get-started.md) и [Архитектура](architecture.md).
