# API Reference

The API is generated by Doxygen from public C# types under `Assets/_KofeyekToolkit/_Scripts`. It deliberately excludes Unity packages and TextMesh Pro.

This is a shared technical reference: it is published once in English and is available from both locales.

Open the [generated KofeyekToolkit API](/Asssets/api/index.html) for namespaces, types, members, and XML documentation.

> **To run the documentation locally, use `npm run docs:start` from the `website/` directory.** Do not run `docusaurus start` directly: `docs:start` generates and verifies the API first.

Run `npm run docs:api` to refresh only the API; `docs:start`, `docs:build`, and `docs:check` generate and verify it automatically.
