# API Reference

The API is generated by Doxygen from public C# types under `Assets/_KofeyekToolkit/_Scripts`. It deliberately excludes Unity packages and TextMesh Pro.

This is a shared technical reference: it is published once in English and is available from both locales.

Open the [generated KofeyekToolkit API](https://candycandlegames.github.io/Asssets/api/index.html) for namespaces, types, members, and XML documentation.

Run `npm run docs:api` from `website/` to refresh it; `docs:start`, `docs:build`, and `docs:check` generate it automatically.
