# Публикация KofeyekToolkit на GitHub Pages

Сайт состоит только из статических файлов и не требует Node.js или сборки.

1. Закоммитьте и отправьте папку `docs/` в репозиторий.
2. На GitHub откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку публикации (например, `main`) и папку **`/docs`**.
5. Сохраните настройки и дождитесь URL опубликованного сайта.

Главная страница сайта находится в `docs/index.html`, а документация — в `docs/docs.html`.
